# Contributing

Start with [AGENTS.md](AGENTS.md) for shared project instructions and
[the contributor guide](docs/source/contributing.rst) for test/database setup,
strict Sphinx builds and browser verification.

Use English for code, comments, commits and public documentation. Keep each
significant feature in its own branch. Add meaningful tests before behavior
changes, run the relevant checks and review the diff before integration.

Report defects with the Python/Django/database versions, a synthetic reproduction,
expected behavior and actual behavior. Do not include credentials, private row data
or sensitive query payloads. Describe the intended workflow for feature requests.

Keep personal plans, transcripts and local agent state out of commits. Documentation
sources are public; generated HTML, local databases, environments and secrets are not.
